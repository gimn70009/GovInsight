# 제출서류 원문 회귀 자료

실제 공개 공고의 HWPX를 기존 파서로 읽은 결과 중 제출 안내 구간만 보존합니다. 테스트에서 네트워크나 AI를 호출하지 않습니다. 기대 목록과 조건은 원문 표의 행/열을 대조했습니다.

- `cbam.txt`: [중기부 CBAM 대응 인프라구축 사업 4차 모집공고](https://www.mss.go.kr/site/smba/ex/bbs/View.do?cbIdx=310&bcIdx=1071591), 신청서류 구간. 11개 항목, 유형별 O/X, EU 증빙의 해당 시 조건, 1개월 이내 발급·마감일 기준 유효 조건을 검증합니다.
- `award.txt`: [중기부 납품대금 연동 우수기업 포상 모집 수정공고](https://www.mss.go.kr/site/smba/ex/bbs/View.do?cbIdx=310&bcIdx=1071647), 신청기간 및 방법/제출서류 구간. 5개 항목과 PDF/HWP·날인 안내를 검증합니다.

- `clean.txt`: [중기부 소공인 클린제조환경조성사업 3차 모집 공고](https://www.mss.go.kr/site/smba/ex/bbs/View.do?cbIdx=310&bcIdx=1071619)의 신청서류 및 가점 구간. 기존 HWPX 파서의 행 순서를 보존하며, 서류별 발급·유효 조건과 대상 없는 `(제출서류 없음)`의 오표시를 회귀 검증합니다.

- `startup.txt`: [중기부 2027년 초격차 스타트업 프로젝트 정부 첫 실증·구매 프로젝트 주관기관 모집공고](https://www.mss.go.kr/site/smba/ex/bbs/View.do?cbIdx=310&bcIdx=1071648)의 신청·접수/제출 서류 구간. HWPX의 원래 셀 주소와 병합 범위를 대조해 서류명 5개, 첫 4개 필수 묶음, 마지막 확인서의 해당 시·민간기관 조건 및 발표자료 대체 조건을 검증합니다. 설명 열을 별도 서류로 세거나 다음 평가 절·장 번호를 끌어오지 않아야 합니다. 평문에 남지 않은 비고 병합 범위는 추정해서 전파하지 않습니다.
