## 표시 및 저장

- 제보 공고의 저장 결과만 5개에서 9개로 보정했다. 신청 조건 4개(공통 신청 형태 1개와 주체별 자격 3개), 제외 조건 5개다.
- 단독 또는 컨소시엄 선택을 보존하고, 연구기관은 6유형 중 하나라는 관계를 유지했다. 기업지원기관의 연구기관·대학 제외는 해당 주체의 설명에 연결했다.
- 인용은 모두 현재 첨부에서 정확히 일치한다. 문장/설명 240자, 인용 600자 제한과 표시 검증을 통과했다.
- DB 쓰기 전 대상 행 잠금, 이전 캐시 백업, 입력 키/본문/첨부 원문/첨부 해시 대조를 수행했다. 1행만 갱신하고 별도 읽기 전용 재조회로 확인했다.
- 14개 공고의 키와 원문·첨부가 그대로이며, 다른 저장 공고 2개의 표시와 캐시는 바뀌지 않았다.
- **이 저장 보정은 원문 검토 결과다. 모델을 새로 호출해 자동 생성한 결과가 아니다.**

## 일반 코드의 적용 범위

`ParticipationRecruitmentScope`는 같은 첨부에서 얻은 모집 문맥과 원래 구역 제목만 사용한다. 생성 문구나 공고 ID·고유 사업명으로 정답을 정하지 않는다. 별도 모집 대상 이름은 전체 역할과 자격/대상 표제를 대조하여 ‘기업’이 ‘기업지원기관’에 잘못 대응하지 않도록 한다.

총괄/세부 연구개발기관은 모집 제목·별도 모집 안내·세부과제 지원유형 표가 모두 확인될 때만 구분한다. 파서가 표 뒤에 다음 자격 절의 제목만 붙인 경우는 그 제목을 빈 경계로 취급한다. 자격 문장까지 붙어 있으면 현재/별도 내용이 섞인 구역으로 남긴다.

통합공고·동시 모집·취소/부정/불명확 문맥·현재 역할을 함께 담은 원문·공통 제외는 보존한다. 한 문장이 인용한 여러 출처 중 하나라도 현재 또는 불명확하면 문장 전체를 제거하지 않는다. 해석할 수 없는 구조의 모집 범위를 완전히 검증하는 기능은 아니다.

frozen request, 출처 ID, 캐시 v6는 유지한다. 기존 결과 표시에도 적용하고, 신규 요청에서는 명시적 참고 구역을 빼므로 유료 재추출을 유발하지 않는다. 단일 모델·low·최대 1회·재시도 0회·출력 4,096토큰·원문 8,000바이트·총입력 20,000바이트·24구역 상한은 그대로다.

## 검증

- AI 신청자격 테스트 374개 및 Ruff 통과. 본문과 한 줄로 붙은 지원대상 회귀 검사 포함.
- 백엔드 최종 단독 실행 1812개 통과(실패·오류·건너뜀 0). 중간 전체 검사에서 기존 `ProposalDraftPersistenceTest`의 마지막 초안 조회 순서 검사가 실패했으며, 관련 검사와 함께 분리 실행한 372개는 통과했다. 이 작업에서 초안 기능은 변경하지 않았다. 중간에 겹쳐 실행한 검사 2회는 테스트 결과 파일 충돌이 있어 결과 집계에서 제외했으며, 모든 실행이 종료된 뒤 최종 전체 검사를 단독으로 완료했다.
- 14개 실제 저장 입력 재생: 캐시 지문 전부 동일. 원문 검토 보정 전에도 제보 캐시의 별도 모집 항목이 표시에서 제외되어 5→4개가 됨을 확인했다.
- 원문 검토 보정 후 Java 투영과 DB 재조회 결과가 정확히 동일한 9개 조건임을 확인했다.
- 프런트 빌드 통과. 저장할 실제 투영 결과를 대체 GET API로 넣어 1440/390/320px에서 9개 조건, 6유형, 설명·원문 펼치기와 가로 넘침을 확인했다. 운영 API를 새로 호출한 브라우저 검사와 구분한다.
- 실제 양자사업 지원대상 원문 복구, 제보 공고의 별도 모집 원문 제외 및 현재 자격 표 보존, 전체 직렬화 입력 예산을 확인했다.
- 유료 모델 호출 0회. 새 추출의 자격 분리·선택지 완전성은 실제 모델 재호출로 검증하지 않았다.

## 남은 작업 및 적용

- 다른 공고의 잘못된 제외 조건, 근거 연결 오류와 미래자동차 각주 경계 누락은 후속 수정 대상이다.
- 양자사업 입력 복구는 신규 추출부터 적용한다. 해당 공고의 기존 잘못된 저장 문장은 이번에 수정하지 않았다.
- 일반 코드 변경은 백엔드·AI 재시작 후 적용한다. 제보 공고 한 건의 검토 보정 결과는 이미 저장했다.
- 작업용 미리보기와 8080을 점유하던 PID만 종료했고 8080이 비어 있음을 확인했다. 서버는 종료 상태로 전달한다.
