# README 화면 이미지 관리

루트 `README.md`는 이 폴더의 PNG를 상대 경로로 표시합니다. 이미지도 문서와 함께 저장소에 커밋하면 GitHub에서 표시됩니다.

| 파일 | 사용 흐름 |
| --- | --- |
| `01-monitoring.png` | 모니터링 대상 설정 |
| `02-analysis.png` | 공고 분석 |
| `03-proposal.png` | 회사 맞춤 사업 제안 |
| `04-draft.png` | 양식별 초안 작성 |

이미지를 교체할 때는 새 캡처를 같은 이름으로 저장하면 됩니다. 원문 내용·회사 정보·계정 및 연락처의 노출 범위를 확인한 뒤 사용합니다. 2026-09-10 이미지는 개발 환경의 저장 결과를 읽어 촬영했으며 촬영 중 공고 수집·모델 생성·알림 발송은 실행하지 않았습니다.

루트 README에서 사용하는 문법:

```markdown
![공고 분석 화면](docs/images/02-analysis.png)
```

원본 화질을 유지하고, 한 이미지에 한 단계의 핵심 영역을 담습니다. 긴 화면을 작게 축소해 붙이기보다 필요한 영역을 직접 캡처하고 설명을 함께 적습니다.
