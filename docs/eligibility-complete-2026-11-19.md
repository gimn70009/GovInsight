# 신청자격 잔여 오류 수정

2026-11-19, 앞선 첨부 원본 대조에서 확인한 남은 오류를 공통 처리와 저장 결과 보정으로 나누어 수정했다. 기존 별도 모집 분리 수정은 유지한다.

## 수정 내용

| 문제 | 공통 처리 | 기존 결과 보정 |
| --- | --- | --- |
| 지원대상 누락 | 앞서 복구한 긴 지원대상 표제의 선택 규칙 유지 | 양자산업협력 공고의 실제 지원대상 1개 복구 |

| 본문과 설명 반복 | 새 정보만 설명하도록 기존 공통 지시 유지. 정확한 문장 중복만 코드로 제거하는 정책 유지 | 연구기획 공고의 중복 설명 2개 제거, 본문·근거 보존 |

## 구현 범위와 보존 정책

- 원문 복구는 공고 ID·사업명·정답 문장에 의존하지 않는다. 신청서 양식 내부의 예시, 다음 추출 구간, 다른 첨부로 연결하지 않는다. 별표의 규정명·제목이 맞지 않거나 연결이 불명확하면 임의로 합치지 않는다.
- 기존 원문 분리 결과로 만든 request와 `s` ID, 캐시 v6는 그대로 둔다. 추가 원문은 내용 기반 `u` ID로 보충한다. 새 입력에서 전체 보충 원문에 포함되는 기존 조각만 중복 제외한다. 저장된 문장의 근거는 변경하지 않는다.
- Python은 보충 원문의 각주·하위 제목을 다시 잘라 버리지 않는다. 원문 합계 8,000바이트·전체 요청 20,000바이트·최대 24구역·출력 4,096토큰·재시도 0회·기존 모델을 유지한다. 최소 표본 요청은 5,945바이트로 기존 6,000바이트 회귀 상한을 지킨다.
- 서류 근거 검사는 공유 예제 11개로 Python/Java 일치를 검증한다. 알려진 주요 서류명과 명시적인 계약 예외를 확인하는 보수적 검사이며, 모든 문장의 의미를 판정하는 장치는 아니다.
- 어순만 다른 의미 중복을 단어 유사도로 지우지 않는다. 본문에 없는 예외·대안·법령 설명이 손실될 수 있기 때문이다. 현재 중복 설명의 제거는 원문을 읽고 수행한 개별 보정이다.

## 저장 결과

- 수정 직전 최신 DB 14건을 읽기 전용으로 수집했다. 저장 자격 결과는 3건이었다.
- `version_id=2`: 잘못된 2개 항목 → 원문과 대응하는 지원대상 1개.
- `version_id=4`: 정상 자격·제외 조건 2개 유지, 반복 설명 2개 → 0개.
- 각 행의 원래 캐시를 별도 백업하고 행 잠금·캐시/본문/첨부 해시/첨부 텍스트/파싱 상태의 동시 변경 검사 후 저장했다. 저장 후 재조회로 일치를 확인했다.
- 14건의 본문·첨부·수집 시각·분석·캐시 키·기존 request는 동일하다. 다른 12건의 캐시를 변경하지 않았고, 앞서 수정한 총괄주관기관 공고의 9개 조건과 화면 투영도 유지했다.

## 검증

- Python 신청자격 회귀 387개, Ruff 통과.
- 백엔드 전체 1819개 회귀와 프런트 빌드 통과(실패·오류·건너뜀 0).
- 현재 14건과 보관된 교육기관 공고의 입력을 실제 코드로 재생했다. 원문 인용은 연속된 원본 구간으로 유지된다.
- 미래자동차: 산정 기간, 부품 범위 별표 1·2, 연구개발비 별표 3, 50% 또는 3%, 평가 80점, 기업집단·제재 제한의 입력 보존을 확인했다.
- 교육기관: 실습장 400㎡, 이륜차 6대, 별도 교육관리자 1명, 강사 선택지·동시 충족·영상 예외·온라인 전용 예외를 확인했다. 선택 원문은 5,745바이트다.
- 두 보정 응답을 대체 API로 화면에 넣어 1440/390/320px에서 조건 수·잘못된 제외 제거·중복 설명 제거·원문 표시·가로 넘침·브라우저 오류를 검사했다. 실제 모델 실행이나 운영 API 통합 검사와는 구분한다.
- 작업용 4197 미리보기를 종료했고 8080 포트가 비어 있음을 확인했다.
- 로컬 검증 자료와 원본 백업은 Git에서 제외된 `backend/build/eligibility-complete-20261119/`에 보관한다.

## 남는 검증 한계

이번 작업의 유료 모델 호출은 0회다. 기존에 확인한 오류의 코드 수정·원문 입력 복구·저장 결과 보정은 검증했지만 새 모델 응답이 모든 조건을 빠짐없이 생성하는지는 재검증하지 않았다. 현재 결과가 없는 11건을 추출 실패나 검증 완료로 계산하지 않는다. 알려진 서류명 밖의 근거 불일치와 표현만 다른 의미 중복에는 추가 의미 검증이 필요할 수 있다.
