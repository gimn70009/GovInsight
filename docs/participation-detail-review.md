2026-11-13. 사용자 첨부 PDF 2~3쪽과 현재 저장 결과(version 3, 조건 7개)를 대조했습니다. 읽기 전용 조회 및 오프라인 재생이며 유료 API 호출·운영 DB 쓰기는 없습니다.

| 지역·입주공간의 적용 사업 | 저장 결과는 사업별로 다른 요건을 공통 항목의 설명 안에 묶고 있음. 사업별로 다른 독립 요건은 별도 항목으로 분리하도록 프롬프트를 명확히 함. 기존 캐시를 자동으로 분해·재작성하지는 않음 |

본문: 총괄매니저는 관련 지원업무를 원활하게 수행할 수 있는 상근 근무자로, 다음 자격 중 하나 이상을 갖춰야 합니다.
