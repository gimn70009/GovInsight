# 사업 담당기관 추출 개선 및 검증 — 2026-10-26

`fix/organization-role-description`에서 역할 표현·기관 이름·표 문맥을 분리해 수정했다. 앞선 제외 단어 보강 이후 137/215였던 고정 표현 진단은 현재 **215/215** 기대 결과와 일치한다. 창업도시의 운영예산 설명 오추출을 제외하면서 실제 공고의 정상 기관 누락도 복원했다.

## 바뀐 처리

1. 역할을 읽는 단계에서 사업 접두어, 번호·괄호·전각 기호, 명시적인 문장형/역순, 한 행의 여러 역할을 처리한다. `주최/주관`은 각 역할과 기관 묶음의 수가 맞을 때만 순서대로 연결한다.
2. 이름은 별도 `ResponsibleOrganizationNames`에서 기관 종류·행정기관·법인 표기·알려진 약칭을 검증한다. 끝 글자 `원·시·도`만으로 금액이나 업무 표현을 기관으로 인정하지 않는다. 산학협력단/운영본부까지 이름을 보존하고, 괄호 약칭·복수 기관 구분자를 따로 읽는다.
3. 기관 표의 업무 설명 셀을 문서 전체의 서식/예시 제목으로 취급하지 않는다. 설명의 전년도 실적 검토 문구도 명시된 현재 역할을 무효화하지 않는다. 명시된 기관명/역할 머리글이 있으면 역순 열도 처리한다. 서식·예시·타 문서 경계에 대한 기존 제외 조건은 유지한다.
4. 근거는 원문 위치에서 잘라 반환한다. 분석용 공백 정규화가 원문 발췌의 빈 줄·CRLF를 변경하지 않는다. 다음 줄의 글머리표, 제한된 목록/명칭 줄바꿈도 처리한다.

API 형식, 저장 본문/첨부, AI 분석, DB와 캐시는 변경하지 않았다. 추가 모델 호출이 없으며 백엔드 재시작 후 상세 재조회부터 적용된다. 같은 상세 조회를 재사용하는 메일에도 적용된다.

## 고정 표현 진단 전후

| 분류 | 입력 수 | 직전 수정 | 현재 |
| --- | ---: | ---: | ---: |
| 기본 역할 표기 | 28 | 28 | 28 |
| 표기와 문장 | 52 | 22 | 52 |
| 기관명 종류 | 35 | 26 | 35 |
| 복수 기관 | 17 | 8 | 17 |
| 표 구조 | 12 | 11 | 12 |
| 업무와 미확정 표현 | 52 | 26 | 52 |
| 문맥 구분 | 12 | 9 | 12 |
| 출처와 문서 경계 | 7 | 7 | 7 |
| **합계** | **215** | **137** | **215** |

입력과 기대값은 이전 진단에서 고정한 자료를 그대로 상시 회귀에 옮겼다. 기관명·역할·순서 및 출처/근거를 검증한다. JUnit에서는 근거가 원문에 실제로 포함되는지 검사하며 공백 정규화로 실패를 숨기지 않는다. 별도로 실제 공고와 기관 종류·일반명사·서식 경계·복합 역할·입력 상한 등을 검사한다.

이 수치는 합성 표현 테스트다. 본문/첨부 변형이 포함되어 있으므로 실서비스 정확도나 독립적인 실제 공고 215건의 성공률을 뜻하지 않는다. 역할 대응이 불명확하거나 알려지지 않은 약칭·기관 형태는 계속 확인 필요로 남을 수 있다.

## 실제 저장 공고 15건

이전에 확보한 현재 버전의 저장 본문·첨부 사본을 오프라인 재생했다. 새 DB 조회·변경 및 유료 API 호출은 없다.

| 공고 | 수정 후 기관/역할 |
| --- | --- |
| 창업도시 조성 프로젝트 창업도시 모집 공고 | 창조경제혁신센터 — 운영기관 / 창업진흥원 — 전문기관 / 중소벤처기업부 — 총괄기관 |
| 산업통상부-에너지공기업 기술나눔 연장공고 | 산업통상부 — 시행부처 / 한국산업기술진흥원 — 전문기관 |
| 전통시장 및 상점가 활성화 지원사업 수정공고 | 중소벤처기업부 — 주최 / 소상공인시장진흥공단·전국상인연합회 — 주관 |
| 나머지 12건 | 직전 추출 응답과 동일 |

- 창업도시는 `프로그램 운영예산 지원`을 계속 제외하고 본문에 명시된 전문/총괄기관을 추가한다. 전문기관의 현장평가 안내, 총괄/전문기관 점검 안내의 실제 원문을 근거로 사용한다.
- 기술나눔 HWPX 110행의 업무 설명이 `신청서` 접두사 때문에 서식 상태를 만들던 문제가 해소됐다. 시행부처와 전문기관을 각각의 표 셀에 연결한다.
- 전통시장 공고는 글머리표가 있는 문의처를 읽으며, 원문 `◦ (주최/주관) 중소벤처기업부/소상공인시장진흥공단, 전국상인연합회`의 역할도 구별한다. 운영 역할이 확인된 동일 기관의 문의처 중복은 기존 규칙대로 제거된다.
- 재생 과정에서 넓은 `원` 접미사를 제거할 때 `한국중소벤처기업유통원`이 누락되는 것을 발견하여 기관 종류 인식과 보존 회귀를 보강했다. 기존 시범구매 기관 응답은 최종적으로 동일하다.
- 나머지 12건이 같다는 것은 기존 정상 결과를 보존한 비교 결과이며, 그중 빈 결과가 전부 정확하다는 인증은 아니다.

## 검증 상태

- 기관 회귀 **252개 통과**: 기존 23개 + 고정 표현 215개 + 실제 원문/경계 보강 14개.
- 최종 전체 백엔드 1,662개 중 1,661개 통과, 기존 `ProposalDraftPersistenceTest`의 최근 조회 순서 검사 1개 실패(오류/건너뜀 0). 해당 클래스 9개를 분리 재실행해 모두 통과했다. 이전 전체 실행은 통과했지만 마지막 전체 실행이 모두 통과한 것으로 보고하지 않는다. 초안 운영 코드는 변경하지 않았다.
- 프런트엔드 빌드 통과. 실제 추출 응답을 모의 GET API로 넣은 3개 공고의 1440/768/390/320px 화면에서 기관명·역할·근거·링크·키보드·가로 넘침 없음을 확인했다. 창업도시 제출서류 6개도 유지된다.
- PC/모바일 캡처를 육안 확인했다. 화면 테스트 서버는 `finally`에서 종료했다. 최종 코드의 15개 공고 응답이 화면 검증 응답과 같음을 재확인했다. 실제 서비스 DB를 변경하거나 메일을 발송하지 않았다. 최종 `git diff --check`와 8080 포트 비움을 확인했다.
