# 신청 자격 프롬프트·원문 연결·검증 일반화 (2026-11-20)

실제 첨부 대조에서 발견한 오류를 공고명·기관명·버전 ID에 의존하지 않는 규칙으로 보완했다. [직전 원문 대조](eligibility-current-review-2026-11-20.md)의 후속 구현이다. 기존 DB 결과를 정답 문장으로 덮어쓰거나 모델을 재호출한 작업은 아니다.

## 변경

- 프롬프트에서 현재 모집의 신청 주체와 사업/유형을 구분하고, 자격표의 각 행을 독립 항목으로 대응시킨다. 해당 사업의 산업 분야나 별도 모집 대상을 임의로 적용 사업 배지로 만들지 않는다.
- 긴 자격 목록은 본문에 대상과 선택 관계를 두고, 설명에 법령명·조항·설립 형태·대상 범위를 빠짐없이 기술하도록 했다. 본문 재진술은 설명에서 제외한다. 효과가 다른 제외 사유를 분리하고, 주석의 제재를 다른 사유에 확대하거나 ‘제외 가능’을 확정으로 바꾸지 않도록 명시했다.
- Python은 명시적인 2열 신청 주체/자격 표에 `required_rows` 줄 번호를 부여한다. 행이 누락되거나 표 전체를 한 조건으로 인용하면 해당 출처를 미해결 상태로 보존하고 관련 요약은 원문 확인 대상으로 표시한다.
- Python 신규 응답과 Java 기존 캐시에 같은 법적 대안·제재 범위 검사를 적용한다. 단일 신청 주체의 인용에 복수 법령이 있는데 표시 가능한 본문·설명에 법령/조항이 빠지거나, 주석의 제재를 독립된 앞선 제외 사유와 합친 경우 정상 요약으로 표시하지 않는다. 의미 검사에 실패한 요약의 설명도 숨기고 사유와 원문을 제공한다.
- ZIP 이름에 ‘서식’이 들어간다는 이유만으로 전체를 버리지 않는다. 허용된 공고 문서에서 제출서류로 참조한 자격 확인서의 제목을 대조해 내부 파일의 점검 구역만 연결한다. 서명란·다른 양식·작성 예시는 포함하지 않는다. 여러 모집 문맥에 동시에 연결되면 확정하지 않는다.
- 같은 공고의 면제·산정 제외 문단을 함께 보충한다. 확인서는 직접 신청자격 다음에 선택하며, 긴 접수 절차보다 우선한다. 예외를 입력 한도 내에 함께 넣을 수 없으면 연결된 확인서도 모델 입력에서 제외한다. 원문은 계속 제공한다.
- 화면의 ‘첨부 자격 확인’에서 점검 구역과 공고 예외를 선택하고 실제 첨부 링크를 열 수 있다. 요약 여부와 관계없이 연결된 확인서 원문을 유지한다.

## 검증

- AI 신청자격 회귀 검사 404개 및 Ruff 통과. 법령 누락/정상 대안, 주석 제재/독립 사유, 행 누락, 표시 불가 설명, 확인서와 예외의 동시 선택 및 입력 우선순위를 포함한다.
- Java 전체 테스트는 최초 실행에서 1,824개 통과했으나 후속 실행에서 신청자격과 무관한 `ProposalDraftPersistenceTest.java:107`의 최근 조회 초안 순서 검사가 실패했다. 전체 통과로 확정하지 않는다. Python과 같은 11개 의미 검사 사례, 실제 투영 경로의 기존 캐시 검사, ZIP 확인서 연결·예외·서명 경계·중복 추출은 별도 신청자격 회귀 검사 376개 통과로 확인했다. 후속 전체 실행에서는 Gradle 결과 파일 기록 오류(EOF/NoSuchFileException)도 발생했으며 마지막 신청자격 단독 실행은 정상 종료했다.
- 프런트 테스트 111개, build·lint 통과.
- 실제 저장 결과를 새 Java 표시 결과로 변환한 뒤 대체 GET API로 1440/390/320px 브라우저를 검사했다. 8조건·3개 신청 구분·2개 원문 확인 표시, 9개 확인서/예외 원문, 각 원문에 맞는 첨부 링크, 가로 넘침 없음 및 브라우저 오류 없음 확인.
- 검증 산출물은 무시되는 `backend/build/eligibility-generalization-20261120/`에 저장했다. 작업 전 파일 백업, 14건 재생 결과, 입력 선택 결과, 브라우저 검사와 화면을 포함한다.

## 적용 범위와 남은 검증

이번 유료 모델 호출과 운영 DB 쓰기는 0회다. 프로젝트의 기본 테스트 규칙에 따라 외부 모델을 대체해 검증했으며, 새 프롬프트의 실제 생성 정확도는 아직 확인하지 않았다. 기존 저장본의 표현만 다른 반복 설명도 자동으로 의미 비교해 삭제하지 않는다. 새 프롬프트는 AI 서비스가 변경 코드를 로드한 뒤 신규 추출에 적용된다. 기존 저장 결과에는 Java의 검증과 첨부 원문 보강이 적용된다.
