# 신청자격 누락 원인 수정과 검증

2026-11-24의 [누락 단계 분석](council-eligibility-loss-2026-11-24.md)에서 확인한 입력 손실, 표 인용 계약, 누락 검증, 본문 예외 지시를 수정했다. 새로운 생성 경로에 적용하는 코드 변경이며 기존 DB의 7조건을 새 생성 결과로 바꾼 작업은 아니다.

## 변경

- Java `ParticipationSourceSelection`은 제한·제외 제목과 명시적 신청/참여 제한, 역할별 기관 정의를 보충 송신한다. 기존 request를 정하는 어휘 사전과 호환 출처 번호 계산은 바꾸지 않는다.
- Python `requirements`는 역할 정의 구역의 전체 문맥을 유지한다. 주관기관 법적 자격표뿐 아니라 공동주관기관, 지역 및 참여기관의 연결 정의를 동사 패턴으로 잘라내지 않는다. `selection`은 제한 구역과 구성요건을 인식한다.
- `completeness`는 설립 근거 표와 가점 행도 누락 검사 대상으로 삼는다. 수량은 숫자·단위의 집합 대신 반복 횟수와 비교 방향을 보존하고, 명시적 전방 수량 구문의 대상도 연결한다. 산단/산업단지·지자체/지방자치단체 및 전후 어순 차이는 허용한다.
- `coverage`는 필수 참여 대상·중심 분야·법적 근거가 인용뿐 아니라 실제 요약에 있어야 충족으로 인정한다. 독립된 누락은 PARTIAL로 남기며 하나의 요건을 인용한 불완전 요약만 검토 대상으로 구분한다.
- `citations`는 원문 줄 번호에 셀·구절 번호를 추가한다. 긴 병합 행의 동일 셀은 입력에 한 번만 표시하되 실제 원문 위치로 복원한다. 셀/구절 인용에서 다른 셀의 수량을 가져오거나 한도 방향을 뒤집는 출력은 거절한다. 최종 인용 600자 제한과 실제 원문 연속 구간 검증은 유지한다.
- 실제 실행하는 `focused` 프롬프트와 필드 설명은 적용 예외를 본문에 함께 쓰도록 통일했다. 수량 제한의 명시적 면제/제한 없음 예외가 상세 또는 직접 인접 주석에만 남으면 검토 대상으로 처리한다.

## 실제 공고 오프라인 재생

기존 읽기 전용 스냅샷을 현재 Java/Python 함수로 재생했다. 운영 DB에는 연결하지 않았다.

| 항목 | 이전 | 수정 후 |
| --- | --- | --- |
| Java 송신 출처 | 14개 | 16개 |
| Python 선택 출처 | 10개 | 12개 |
| 주관·공동주관기관 구역 | 930자 중 157자 | 930자 전체 |
| 주관기관 법적 자격표 검사 | 0행 | 4행 |

| 가점 947자 병합 행 | 줄 전체 인용 시 600자 초과 | 실제 313자 셀 인용 가능 |
| 지역산업진흥원 필수 참여 | 요약에 없어도 covered=True | covered=False |
| 기존 7조건 재검사 | 잘못 통과한 본문 존재 | 1번 수량 누락·4번 본문 예외 누락 식별 |

동결 request는 이전 객체와 완전히 같고 캐시 키 계산은 변경하지 않았다. 원문 입력은 15,299/32,000바이트이며 전체 입력도 48,000바이트 이내다. 반복 셀 축소 후 원문 내용 자체는 변경하지 않는다. 기존 7개 문구는 재생 전후 동일하며 상태와 진단만 새 검사로 평가했다. 이는 실제 모델이 다시 생성한 응답이 아니다.

재현 도구와 상세 결과는 Git 제외 `backend/build/council-fix-20261124/`에 있다. 회귀 테스트에는 제공된 공개 공고의 필요한 원문 4구역과 기존 조건만 넣었으며 DB 접속 정보나 조회 스냅샷 전체를 넣지 않았다.

## 검증 및 한계

AI 신청자격 테스트 463개, 백엔드 전체 테스트 1,846개가 통과했다. 백엔드 실패·오류·건너뜀은 0개다. 변경 Python Ruff, diff 검사, 8080 비점유도 확인했다. 첫 백엔드 실행에서 새 테스트의 보충 ID 접두어 기대값이 실제 `u` 해시 계약과 달라 실패했으며 기대값 수정 후 전체 테스트를 다시 통과했다.

추가 회귀는 원문 역할/제한 보존, 서로 다른 대상의 동일 수량·비교 방향·대상 간 수량 교환, 필수 참여 누락, 법적 가점 대상 누락, 긴 셀 인용과 잘못된 주소/수량, 본문 및 인접 주석 예외를 검사한다. 기존 사업·모집 범위와 캐시 호환 테스트도 함께 통과했다.

모델·추론 설정·호출 1회·재시도 0회·입출력 한도를 유지한다. 실제 모델 호출·DB 쓰기·브라우저 재접속은 수행하지 않았다. AI/백엔드를 다시 실행하고 대상 공고의 신청자격을 새로 생성해야 신규 결과에 적용된다. 저장 캐시를 조회하거나 서버만 재시작하면 기존 7조건이 자동 수정되지는 않는다.

수량 대상·필수성·예외 검사는 명시적인 구조와 표현을 대상으로 한다. 모든 한국어 바꿔쓰기의 의미 동등성, 임의 조건의 논리 관계, 모든 누락을 보장하는 범용 의미 검증은 아니다. 안전한 구절 경계가 없는 긴 원문은 임의로 자르지 않고 미해결로 남는다. 실제 신규 생성의 전체 조건 반영률은 후속 확인 항목이다.
