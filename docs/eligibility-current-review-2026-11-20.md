# 현재 신청 자격과 첨부 원본 대조

2026-11-20 현재 신청 구분과 화면 펼침 기능은 정상이나, 연구기관 자격의 누락, 제외 조건의 의미 변경, 세부 설명 반복이 남아 있다. 첨부 자격 확인서의 추가 점검 항목도 현재 입력과 표시에서 제외된다. 따라서 신청 자격이 모두 정확하게 나온다고 판단할 수 없다.

## 현재 데이터와 검증 범위

- 현재 DB는 `2026-11-20 07:37:33.0208282` 수집본 14건이다. 신청자격 저장 결과가 있는 공고는 **2027년도 소재·부품·장비 양산성능평가지원사업 총괄주관연구개발기관 모집 공고** 1건이다. 현재 입력 지문과 저장 키가 일치하며 신청 조건 4개·제외 조건 4개·설명 8개가 표시된다.
- 11월 19일의 3건·개별 보정 결과와 현재 저장본은 다르다. 과거 보정본을 현재 정상 결과로 계산하지 않았다. 현재 수집본에 결과가 없는 나머지 13건은 생성 오류나 정확도 검증 완료로 판정하지 않았다.
- 대상의 공고 HWPX와 신청서식 ZIP을 공개 URL에서 새로 내려받아 HTTP 200 및 현재 DB SHA-256 일치를 확인했다. 공고 2·3·7쪽과 ZIP 내부 `붙임4. 신청 자격 적정성 확인서.hwpx`의 2쪽을 로컬 변환 PDF 이미지로 판독했다. 보관 원본 8개도 현재 DB의 첨부 해시와 대응함을 확인했다. 다른 공고의 최종 표시 품질은 이번 검증 표본으로 계산하지 않았다.
- 현재 Java 코드로 DB 저장 결과를 화면 데이터로 변환하고, 현재 프런트를 빌드하여 대체 GET 응답으로 1440·390·320px에서 재생했다. 운영 API의 인증·메모리 캐시까지 포함한 통합 검사는 아니다.
- DB 조회는 읽기 전용 트랜잭션과 rollback을 사용했다. 제품 코드·운영 DB 변경 및 추가 모델 호출은 없다.

## 확인된 문제

### 연구기관 대안과 법적 범위 누락

공고 3쪽의 연구기관 자격표는 6개 유형을 열거한다. 현재 본문과 세부 설명에는 **산업기술혁신 촉진법 제42조에 따른 전문생산기술연구소**가 없다. 마지막 유형도 `민법 또는 다른 법률에 따라 설립된 산업기술 분야의 법인인 연구기관` 대신 `산업기술 분야의 연구기관 등`으로 줄어 법적 설립·법인 조건이 보이지 않는다. 정부출연연구기관의 두 법적 근거와 과학기술분야 법률 제2조도 설명에서 생략되어 있다.

원문 근거를 펼치면 전체 표를 볼 수 있고, 현재 모델 선택 입력에도 해당 문구가 있다. 따라서 이 사례는 첨부 파싱/입력 누락이 아니라 **현재 저장 요약과 검증의 누락**이다. 당시 모델 원응답이 없어 생성 내부의 원인까지 확정하지 않았다.

### 제외 가능성과 제재 범위 변경

공고 7쪽은 목적에 부합하지 않거나 시행계획 요건을 갖추지 못하면 `지원제외 가능`으로 안내한다. 다음 주석은 **허위 기재** 발견 시 지원제외·협약해약·제재 등의 조치가 가능하다고 별도로 설명한다.

현재 문장은 세 사유를 합쳐 `... 요건을 갖추지 못하거나 허위 기재 사실이 발견된 경우 지원에서 제외되고 협약해약 및 제재 조치가 가능합니다`라고 표시한다. 목적/요건 미충족에 대해서도 제외가 확정된 것처럼 쓰고, 허위 기재에 연결된 제재 조치를 다른 사유까지 넓혀 읽히게 한다. 세부 설명이 허위 기재를 다시 명시하더라도 본문 오류를 해소하지 못한다. `또는` 관계 자체는 현재 문장에 남아 있으므로 과거의 OR→인과 변경 문제와 구분한다.

### 본문을 반복하는 세부 설명

다음 네 설명에는 본문에 없는 추가 정보가 없다.

1. 협·단체: 비영리법인·주무부처 등록 조건 반복.
2. 기업지원기관: 공통운영요령 제3조·비영리기관·연구기관/대학 제외 반복.
3. 신청 형태: 단독 또는 컨소시엄 반복.
4. 의무사항 불이행: 보고서·기술료·정산금·환수금 목록 반복.

NTIS 제재정보·유사과제 확인 방법은 본문에 없는 유용한 추가 정보다. 모든 설명을 삭제해야 한다는 결과는 아니다. 허위 기재 설명은 본문의 제재 내용을 반복하면서 적용 사유를 좁혀 다시 쓰는 상태다.

### 첨부 자격 확인서의 점검 항목 제외

신청서식 ZIP의 붙임4에는 체납·채무불이행·파산/회생·재무 상태·참여율 등의 점검 항목과 예외가 있다. 이 내용은 DB 추출 텍스트에 존재하지만 현재 Java 입력 후보, Python 최종 선택 입력, 화면의 8조건에 없다.

`ParticipationCategorySources.allowed()`는 파일명에 `참고자료`, `서식`, `양식` 등이 있으면 제외한다. 대상 ZIP 이름이 `(붙임) 신청서식 및 참고자료.zip`이어서 바깥 ZIP 단계에서 제외되며, 원문의 자격 확인서를 별도로 판단할 기회가 없다. 현재 화면에는 이 추가 확인서의 점검 누락을 알리는 안내도 없다.

다만 확인서에는 기업에만 적용되는 재무 항목과 일반 서식 조건이 섞여 있다. 확인서 2쪽의 동시수행 과제 수 제한은 본 공고 2쪽의 **총괄주관기관 참여연구원(연구책임자 포함)은 과제 수 산정 제외** 문구와 함께 해석해야 한다. 확인서 전체를 그대로 신청 불가 조건으로 추가하는 것은 부정확하다. 필요한 후속 작업은 참조 서식의 조건·적용 주체·공고별 예외를 연결하고, 불명확한 것은 원문 확인 대상으로 구분하는 것이다.
