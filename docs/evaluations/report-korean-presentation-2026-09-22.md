# 한국어 보고서 안내 표시 검증

## 변경

- 모델의 원문 인용·발췌와 한국어 표시문을 구분했다. 검증용 text를 모델이 중복 작성하면서 출처에 없는 라벨을 넣던 문제를 줄이기 위해, 모델은 인용/fragments/한국어 표시만 반환하고 코드는 발췌 값을 만든다.
- 인용 존재·구절 순서 검증 후 표시문의 숫자/날짜/연락처/URL을 대조한다. 영문 월 이름과 한글 날짜를 정규화하고, 비율 등의 이상/이하 방향 변경도 차단한다. 완전한 의미적 함의 검증기는 아니다.
- 역할/국가별 배열 값을 줄 단위로 표시한다. 슬래시가 있는 URL은 자르지 않는다. 한쪽 제출 시 제외 원문 조건은 모델의 접수 안내에서 누락돼도 보존한다.
- 선정/심사 결과 안내에서는 별도 신청 행동이 없는 경우 누락 경고를 생략한다. 실패 시에도 긴 원문/영문/깨진 표를 그대로 노출하지 않고 짧은 정보와 원문 링크를 유지한다.

## 자동·화면 검증

- AI 전체 739개 회귀 테스트 및 변경 Python Ruff 검사 통과.

- 메일의 여러 안내 값, 문의만 있는 결과 공고 제목, HTML 이스케이프, 구형 본문 호환을 확인했다. 백엔드 342개 테스트 통과.
- 프런트엔드 빌드·11개 테스트 통과. ESLint 오류 0개, 기존 DocumentsPage 경고 2개 유지.
- 실제 HTML 메일과 실제 웹 컴포넌트를 Chromium 데스크톱/390px/320px로 검사했다. 안내 9개가 구분되고 양식 링크가 유지되며 가로 넘침과 브라우저 오류가 없었다. 화면 예시는 합성 회귀 데이터이며 실제 모델 결과를 꾸며 만든 정확도 증빙이 아니다.
- 자동 테스트는 실제 모델 API·메일/Telegram·운영 DB를 호출하지 않는다.

## 공개 공고 수동 점검 및 남은 한계

이전 점검에서 저장한 KIAT 스페인 국문 공고 PDF·양식 ZIP의 파싱 결과와 사용자가 제공한 영문 안내를 사용했다. 전체 게시글 HTML 및 운영 요청을 재생한 검증은 아니다.

최종 구조 전 실제 호출에서 30초 시간 초과 2회와 28.0초 응답 1회를 확인했다. 28.0초 응답은 검증용 원문을 모델이 다시 쓰면서 정상 정보까지 탈락하는 사례를 드러냈다. 구조를 간소화한 최종 호출은 27.8초에 응답했으며 원문 근거와 한국어 대상·접수·해외 문의를 반환했다. 이는 단일 사례이며 평균/P95 성능이나 품질 향상률을 뜻하지 않는다.

저장한 최종 모델 출력은 외부 재호출 없이 후처리를 재검증했다. 라벨 뒤 물결표 마감일이 잘못 탈락하던 부분과 국가별 줄 분리, 원문 동시접수 제외 조건 보존을 보완했다. 국내 문의가 원문에 있어도 모델이 해외 문의만 선택하는 누락, 전체 제출서류 근거 부족은 남아 있다. 모든 자격·조건·문의처·서류를 빠짐없이 추출했다고 주장하지 않는다. 정상으로 보이는 번역의 의미 오류도 자동 검사만으로 모두 잡지 못한다.

1회/공고, 30초/공고·60초/작업 제한을 유지했다. 운영 자동 재시도나 별도 번역 호출은 추가하지 않았다. 모델 실패 시에도 보고서는 기존 대체 경로로 생성되나 세부 정보가 줄어들 수 있다.

기존 저장 보고서는 재전송으로 문장이 바뀌지 않는다. 백엔드·AI 서버 재시작 및 프런트엔드 새 빌드 적용 후 새 보고서를 생성해야 한다. 실제 수신 메일 클라이언트에서의 도착·렌더링은 검증하지 않았다.
