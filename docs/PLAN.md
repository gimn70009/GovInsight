| 문제 | 바꾼 점 | 확인한 결과 |

| 한국어 초안의 문체 검사에서 불필요한 재시도 가능성 | 명확한 줄바꿈·마침표 보정, 문체 오류의 항목·문장 위치 전달 | 회귀 테스트에서 형식 보정은 본문 호출 1회, 실제 문체 오류는 제한된 재시도·실패 처리 확인 |
| 재작성 중 실패·중복 요청 | 요청 ID·버전 검사, 성공 시 교체, 직전 초안 보관 | 기존 본문 보존·재전송·충돌·복원 테스트 통과 |
| 수정 공고에서 첨부 변경 전후 근거 누락 | 이전 첨부 전달·본문 차이 비교, 두 번째 설명을 변경 중심으로 지정 | 첨부만 변경·추가·삭제·읽기 실패·중복 이름·긴 문서 및 모델 입력 경로 회귀 테스트 통과 |
| 시간 초과 재시도가 오류 문구에 의존하고 출력 분량은 동일 | 예외 종류·원인 판별, 입력 축소와 필수 정보를 보존하는 간결한 작성 지시 | 시간 초과별 두 번째 모델 입력·출력 지시 및 기존 부분 결과 보존 회귀 테스트 통과 |

접수 종료 오판 경로와 법률 설명의 문체 보정을 완료했습니다. 기존 저장 결과에는 화면 표시 보정이 적용되며, AI 생성 단계 보완은 이후 새 분석에 적용됩니다.

2026-09-11 한국어 초안 검증 보완 후 AI 전체 테스트 **479개 통과**, 새 검증·테스트 파일의 Ruff 검사 통과를 확인했습니다. 외부 모델은 대체했으며 실제 최초 성공률·응답 시간·내용 정확도의 향상은 아직 측정하지 않았습니다. 제공된 운영 로그에는 실패 본문이 없어 해당 사례의 직접 원인은 확정하지 않았습니다.

2026-09-11 수정 공고 비교 보완 후 **백엔드 290개·AI 497개 테스트 통과**를 확인했습니다. 비교 모듈·도구·입력 스키마·새 비교 테스트의 Ruff 검사와 공백 검사도 통과했습니다. 모델 응답은 대체 객체로 검증했으며 실제 공고에 대한 변경 해석 품질은 별도 평가가 필요합니다. 이미 저장된 분석은 자동 재작성하지 않습니다.

2026-09-11 시간 초과 재시도 보완 후 **AI 전체 테스트 524개 통과**를 확인했습니다. 새 정책·테스트 및 분석 에이전트의 Ruff 검사와 공백 검사도 통과했습니다. 필수 필드·응답 형식·기존 부분 결과 보존을 유지했으며 실제 모델의 완료율·정보 보존율 개선은 아직 측정하지 않았습니다.

2026-09-11 접수 종료 오판·문체 혼용 보완 후 **백엔드 291개·AI 532개·프론트 회귀 테스트 4개 통과**를 확인했습니다. 프론트 빌드와 린트 오류 0개를 확인했으며 기존 React Hook 경고 2개는 남아 있습니다. 새 문체 모듈·공고 쌍 해석 모듈의 Ruff 검사를 통과했고, 기존 장문 줄이 있는 법률 점검 모듈은 E501을 제외한 검사를 통과했습니다. 날짜·시각 경계, 요약의 종료 문구 오탐, 과거 긴급도 문구 제거, 문체 보정 시 조건·예외·원문 보존, 실패 유형만 재시도를 회귀 테스트했습니다. 모델 호출은 대체했으며 사용자가 알려준 공고의 실제 저장 화면은 직접 재검증하지 못했습니다.

2026-09-11 반복되는 한국어 초안 문체 실패 보완: 괄호·인용부호·URL 내부 마침표의 문장 구분 오탐을 수정하고, 정확한 실패 문장과 해당 항목만 전달하는 문체 재시도로 변경했습니다. 정상 본문과 회사 근거·확인 사항은 코드에서 보존합니다. **AI 전체 547개 테스트와 변경 모듈·회귀 테스트의 Ruff 검사 통과**를 확인했습니다. 외부 모델은 대체했으며 실제 실패 본문이 제공되지 않아 운영 사례의 정확한 문장 형태나 성공률 개선은 아직 확인하지 못했습니다.
