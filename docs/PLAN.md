# 현재 작업 계획

이 문서는 현재 목표, 진행 상태, 확정된 다음 작업과 미결정 사항만 관리한다. 완료된 작업을 날짜별로 누적하지 않으며, 현재 동작은 [DESIGN](DESIGN.md)에 반영한다.

## 현재 단계

실행 가능성의 배점·최소 준비 기간·상한을 코드로 계산하며, 최초 저장 전의 기본 설정에도 같은 채점을 적용하도록 보완했다. 신청 자격 추출의 추가 보정이나 회사 적합도·사업 매력도의 채점 방식 변경은 이번 범위에 포함하지 않는다.

## 현재 목표와 완료 상태

추가 채점 모델 호출 없이 항목별 판단 근거를 받아 실행 가능성 점수와 설명을 코드로 일치시킨다. 저장된 예전 결과가 새 정책으로 갱신될 경로도 마련한다.

- [x] 분석의 구조화 출력과 프롬프트를 항목별 상태·근거 중심으로 변경한다.
- [x] 준비 기간·배점·미확인 및 결격 상한과 최종 설명을 함께 계산한다.
- [x] 채점 정책 버전으로 이전 결과를 재평가하고 중복·이전 정책의 덮어쓰기를 방지한다.
- [x] 저장 전의 기본값도 버전 0 스냅샷으로 전달하고 구형 결과를 재평가한다.
- [x] 설정 화면의 기본값 적용 안내를 실제 동작과 일치시킨다.
- [x] 기본값·저장값의 채점 관련 모의 AI·백엔드 회귀 테스트와 프런트엔드 검증을 마친다.

유료 모델 재실행과 운영 저장 결과의 일괄 갱신은 이번 검증에 포함하지 않는다. 실제 생성의 정확도·토큰 비용·지연은 모의 회귀 테스트만으로 확정할 수 없다.

## 다음 작업

반영 후 다음 모니터링에서 다시 수집되는 구형 정책 공고는 한 번 전체 재분석된다. 추가 기능 변경이나 별도 유료 실험은 확정하지 않았다.

다음 개발 범위를 정하기 전에 남아 있는 판단은 **현재 품질을 어느 범위까지 수용할지**다. 신청 자격 본문과 사업·신청 주체 라벨을 구분하고, 수집·파싱·입력 선택 단계의 누락과 생성 결과의 오류를 섞지 않아야 한다. 현재 평가에서 수용할 한계와 반드시 고쳐야 할 오류 유형이 정해지면 필요한 작업만 우선순위로 올린다.

## 보류된 품질 검증

아래는 과거 미완료 기록에서 남은 검증 과제다. 후속 구현이나 유료 재실험이 확정된 목록은 아니다.

| 남은 확인 | 재개 시 완료 기준 |
| --- | --- |
| 신청 자격의 전체 조건 반영과 의미 분류 | 개선에 사용하지 않은 공고에서 표 행·대안·예외·각주를 원문과 대조하고 누락·오분류를 구분한다. |
| 적용 사업·신청 구분 라벨 및 중복 표시 | 조건별 인용과 실제 사업·신청 주체가 일치하는지 확인하고 본문·세부 설명의 중복을 따로 집계한다. |
| 비용 대비 품질의 수용 범위 | 표본 범위와 처리 단계를 명시하고 OCR·분석·신청 자격 등의 호출 비용을 구분해 품질과 함께 판단한다. |

기존 저장 응답을 재생한 결과와 새 모델 생성 결과는 구분한다. 이미 구현된 과거 개선안을 다시 미완료 작업으로 등록하지 않는다.

## 갱신 방식

작업이 확정되면 작은 실행 항목과 완료 기준을 추가하고, 완료 후에는 진행 상태와 현재 설계만 갱신한다. 오래된 완료 체크리스트, 테스트 개수, 실행 로그와 실험 비교는 누적하지 않는다. 기능·정책 변경 시 DESIGN의 해당 절을 고치고 이전 정책을 함께 남겨 두지 않는다.
