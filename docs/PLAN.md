# GovInsight 개발 계획

## 문서 사용 방법

- 이 문서는 개발 순서와 진행 상태를 관리한다.
- 세부 설계와 기능 동작은 `DESIGN.md`에서 관리한다.
- 작업을 시작할 때 현재 단계의 미완료 항목을 확인한다.
- 작업을 완료하고 검증한 뒤 체크박스를 갱신한다.
- 아직 결정되지 않은 작업은 구현 직전에 사용자와 확정한다.
