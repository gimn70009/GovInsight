# 구현 현황과 다음 과제

**현재 단계:** 수집부터 분석·사업 제안·초안 작성까지 주요 사용 흐름을 구현했습니다. 기관과 양식의 범위를 넓혀 정확도를 검증하고 운영 안정성을 보완하는 단계입니다.

[프로젝트 소개](../README.md) · [설계 요약](DESIGN.md)

## 구현한 범위

| 영역 | 현재 동작 |
| --- | --- |
| 모니터링 | 기관·게시판 관리, 수동 실행, 요일·시각 기반 자동 실행 |
| 수집·변경 감지 | 기관별 수집, PDF·HWP·HWPX·ZIP 처리, 파일 내용까지 비교하는 버전 관리 |
| 공고 분석 | 원문·첨부 근거에 따른 요약, 회사 관련성·신청 조건 검토 |
| 사업 검토 | 참여 방향과 준비사항, 유사 공고 비교와 함께 신청할 때의 주의사항 |
| 신청서 초안 | 양식 선택, 국문·영문 작성, 자동 저장, 재작성·직전 초안 복원 |
| 관리 화면 | 문서 검색·필터·북마크, 실행 경고 도움말, Telegram 수신자·발송 내역 |

## 개발 중 해결한 문제

| 문제 | 바꾼 점 | 확인한 결과 |
| --- | --- | --- |
| 목적이 다른 공고를 유사하게 연결 | 미확인 문구 제외, 목적 복구, 선정 기준 통일 | 소규모 개발 자료에서 동일 사업 2쌍 연결·다른 목적 52쌍 오탐 없음 |
| 검색 후보가 늘면서 반복 계산 증가 | 문서 특징·통계 캐시, 상위 후보 선별 | 합성 후보 5,000건의 순위 계산 p95 6.034 → 1.309ms |
| 영문 초안이 형식 검사에서 반복 실패 | 표기 정리 후 문단 검증, 실제 미완성 문장 구분 | 회귀 테스트에서 정상 형식은 추가 모델 호출 없이 처리 |
| 한국어 초안의 문체 검사에서 불필요한 재시도 가능성 | 명확한 줄바꿈·마침표 보정, 문체 오류의 항목·문장 위치 전달 | 회귀 테스트에서 형식 보정은 본문 호출 1회, 실제 문체 오류는 제한된 재시도·실패 처리 확인 |
| 재작성 중 실패·중복 요청 | 요청 ID·버전 검사, 성공 시 교체, 직전 초안 보관 | 기존 본문 보존·재전송·충돌·복원 테스트 통과 |

측정 조건과 검증 코드는 [유사 공고](evaluations/notice-similarity-2026-09-10.md), [영문 초안](case-studies/english-draft.md), [재작성](case-studies/draft-regeneration.md)에서 확인할 수 있습니다.

## 검증 현황

2026-09-10 기능 수정 당시의 기록입니다. 이번 문서 정리로 모든 외부 연동을 다시 실행한 것은 아닙니다.

| 범위 | 결과 | 해석 범위 |
| --- | --- | --- |
| 백엔드 | 288개 테스트 통과 | 서비스·저장·API 검증, 테스트 DB는 H2, 외부 호출은 대체 |
| AI 모듈 | 443개 테스트 통과 | 파싱·분석 흐름·출력 검증, 외부 사이트·모델 호출은 대체 |
| 프론트엔드 | 빌드 통과, 린트 오류 0개 | 기존 React Hook 경고 2개 남음 |
| 유사 공고 | 실제 저장 공고 11건·55쌍 평가 | Codex 초기 라벨, 독립 검수·미사용 평가셋 없음 |
| 브라우저 | 실제 저장 결과 조회, 재작성 상태 전환 확인 | 실제 데이터 조회와 모의 API 실패·응답 유실 시나리오를 구분해 확인 |

2026-09-11 한국어 초안 검증 보완 후 AI 전체 테스트 **479개 통과**, 새 검증·테스트 파일의 Ruff 검사 통과를 확인했습니다. 외부 모델은 대체했으며 실제 최초 성공률·응답 시간·내용 정확도의 향상은 아직 측정하지 않았습니다. 제공된 운영 로그에는 실패 본문이 없어 해당 사례의 직접 원인은 확정하지 않았습니다.
