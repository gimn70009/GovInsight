## 원인 확인

- 현재 모델 입력에 원문의 주무부처 등록, 연구기관 6개 유형, 연구기관·대학 제외, 서류명 안 법인 조건이 모두 있었다. 입력에서 빠진 정보를 복구하는 문제가 아니었다.
- 기존 제출 조건 화면의 서류명 반복은 원문 파서가 남긴 조건이다. 해당 행의 검증된 DOCUMENT 설명이 없으면 이전 중복 제거 로직도 적용할 수 없다.
- 실제 raw 응답은 조건 문장을 생성했지만 quote에 표 순번·별개 수량을 포함하여 숫자 검증에서 탈락했다. 일부 문장 자체에도 조건을 다른 서류로 확대하는 의미 오류가 있어 검증 완화로 해결해서는 안 된다.
- 실제 SDK 경로를 네트워크 없는 MockTransport로 점검했다. 전송 직전 시스템 지시문·엄격한 출력 스키마·모델·low·출력 한도가 그대로였고, 실제 응답을 재생한 결과도 저장한 검증 결과와 일치했다. 호출 경로에서 지시문이 사라진 증거는 없었다.
- 두 실험만으로 모든 공고에서 프롬프트 개선이 불가능하다고 단정하지 않는다. 이번 변경이 해당 공고에서 안정적으로 작동한다는 근거를 얻지 못한 것이다.
