# GovInsight

**공공기관 공고의 발견부터 회사 맞춤 검토, 신청 준비까지 연결하는 AI 서비스입니다.**

GovInsight는 여러 공공기관의 공고와 첨부 문서를 수집하고, 회사 정보에 맞춰 사업 기회와 신청 조건을 정리합니다. 새로운 공고와 변경 사항을 확인한 뒤, 참여 방향을 검토하고 실제 첨부 양식에 맞는 신청서 초안을 작성할 수 있습니다.

## 프로젝트 소개

지원사업과 협력 기회를 찾는 담당자는 기관별 게시판을 확인하고, 공고문과 첨부파일을 읽고, 회사가 참여할 수 있는지 판단해야 합니다. 관심 있는 공고를 찾은 뒤에도 변경 사항을 추적하고 제출서류와 작성 양식을 준비하는 일이 이어집니다.

GovInsight는 이 과정을 하나의 서비스로 묶습니다. 공고 탐색과 문서 정리를 자동화하고, 회사와의 관련성·신청 자격·준비 사항을 함께 제공해 담당자가 사업 검토에 집중할 수 있도록 돕습니다.

주요 사용 대상은 공공 지원사업, 연구개발 과제, 사업화 지원과 협력 기회를 검토하는 기업의 사업기획·연구개발·정부과제 담당자입니다.

## 주요 장점

### 여러 기관의 공고를 한곳에서 관리

등록한 게시판을 수동 또는 예약 일정에 따라 확인하고, 새 공고와 수정 공고를 모아 볼 수 있습니다. 검색·우선순위 필터·북마크로 관심 공고를 관리하고, 보고서 알림으로 후속 검토를 이어갈 수 있습니다.

### 우리 회사의 기준으로 사업 기회를 검토

회사 정보와 관심 분야, 보유 기술·실적·인증 등을 분석에 반영합니다. 공고의 주요 내용과 함께 회사와의 접점, 참여 가능성을 검토할 조건, 준비할 사항을 정리하고 기회점수로 검토 순서를 정하는 데 도움을 줍니다.

### 변경 사항과 판단 근거를 함께 확인

게시글 본문뿐 아니라 첨부파일의 내용 변경도 추적합니다. 수정 공고에서는 변경 전후와 회사에 미치는 영향을 살펴볼 수 있고, 신청 조건의 설명과 원문 근거를 연결해 확인할 수 있습니다.

### 검토 결과를 신청 준비로 연결

공고 분석에서 사업 제안, 제출서류 확인, 양식별 초안 작성으로 이어집니다. 실제 첨부 양식의 작성 항목을 바탕으로 국문·영문 초안을 만들고, 저장·재작성·직전 초안 복원 기능으로 내용을 다듬을 수 있습니다.

## 주요 기능

| 기능 | 제공 내용 |
| --- | --- |
| 공고 모니터링 | 기관·게시판별 수집 범위와 활성 상태 설정, 수동 실행, 요일·시각 기반 예약 실행 |
| 변경 감지·이력 관리 | 제목·본문·첨부파일 내용을 비교해 신규·수정·변경 없음을 구분하고 문서 버전과 실행 이력 보관 |
| 첨부 문서 분석 | PDF·HWP·HWPX·DOCX·XLSX와 ZIP 내부 문서의 텍스트·표를 읽고 분석 자료로 활용 |
| 공고 요약·회사 맞춤 분석 | 핵심 내용, 회사와의 관련성, 중요한 검토 조건과 변경 사항 정리 |
| 신청 자격·제출 안내 | 신청 주체, 업력·매출·업종·인증·실적 등의 조건과 지원 제외, 제출서류·유의사항·원문 근거 제공 |
| 사업 제안 | 회사 상황을 반영한 참여 방향, 논의할 안건과 준비 사항 제시 |
| 유사 공고 비교 | 저장된 공고 중 관련 후보를 찾아 사업 목적·신청 조건·원문 조항 비교 |
| 신청서 초안 작성 | 첨부 양식의 실제 작성란 확인, 국문·영문 초안 생성, 저장·재작성·직전 결과 복원 |
| 공고 검색·북마크 | 기관·게시판·제목 검색, 우선순위 필터, 관심 문서 보관 |
| 보고서·알림 | 분석 결과와 준비 사항을 보고서로 정리하고 Telegram·이메일 채널별 수신자와 발송 이력 관리 |

## 사용 흐름

1. **회사 정보를 설정합니다.** 현재 사업 분야와 보유 역량을 등록하고, 관심 분야와 기회점수 기준을 정합니다.
2. **모니터링 대상을 정합니다.** 확인할 기관·게시판과 수집 범위를 설정하고, 필요할 때 실행하거나 자동 일정을 등록합니다.
3. **새 공고와 변경 내용을 검토합니다.** 공고 요약, 회사 관련 분석, 신청 자격과 제출 안내를 원문 근거와 함께 확인합니다.
4. **참여 방향을 구체화합니다.** 사업 제안과 유사 공고 비교를 통해 논의할 사항과 준비할 자료를 정리합니다.
5. **양식에 맞는 초안을 작성합니다.** 작성할 첨부 양식을 선택하고 생성된 내용을 검토·수정하며 신청 자료를 준비합니다.

보고서 자동 발송을 설정하면 등록한 수신자에게 Telegram 또는 이메일로 결과를 전달할 수 있습니다.

## AI 활용 방식

공고 분석의 근거 조사 단계에서는 AI 에이전트가 현재 공고, 첨부 문서, 회사 정보와 이전 버전 중 필요한 자료를 조회합니다. 제공된 도구 안에서 조회 순서를 선택하고, 읽은 결과에 따라 추가 근거를 확인합니다.

이후 모델이 근거를 바탕으로 분석·신청 조건·제안·초안을 작성하고, 코드는 결과 구조와 인용, 수치·조건 등 확인 가능한 항목을 검사합니다. 수집·파싱·변경 감지·저장은 정해진 프로그램 흐름으로 처리하며 모델과 도구 호출에는 횟수·시간 제한을 둡니다.

분석과 생성 결과는 담당자의 검토를 돕는 자료입니다. 참여 여부와 제출 내용은 연결된 공고 원문 및 실제 회사 정보를 함께 확인해 판단할 수 있도록 구성합니다.

## 기술 구성

| 영역 | 주요 기술 | 역할 |
| --- | --- | --- |
| Frontend | React, TypeScript, Vite | 모니터링·분석 조회, 회사 설정, 공고 비교와 초안 편집 화면 |
| Backend | Java, Spring Boot, Spring Security, Spring Data JPA | 인증, 작업 조율, 변경 감지, 데이터 저장·조회, 예약 실행과 알림 |
| 수집·AI | Python, FastAPI, Playwright, LangChain, LangGraph, OpenAI API | 게시판 수집, 문서 파싱, 근거 조사와 분석·생성 |
| 데이터베이스 | Oracle | 문서 버전, 실행 이력, 분석·제안·초안·보고서와 설정 저장 |
| 알림 | Telegram Bot API, SMTP | 채널별 보고서 전송과 수신자 관리 |

Spring Boot가 데이터와 작업 상태를 관리하고 Python이 수집·AI 처리를 수행합니다. 오래 걸리는 작업은 백그라운드에서 처리하며, 저장된 결과를 조회하고 재사용하도록 구성했습니다.
